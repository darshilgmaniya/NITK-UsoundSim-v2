# Transducer inputs
Required from Transducer team: n_elements, pitch_m, frequency_min_hz, frequency_max_hz, center_frequency_hz. Optional: element width/height and material. Edit `config/transducer_interface.json`. For the Philips L12-4 reference, 128 elements and 4–12 MHz are documented; pitch is not given on the product page, so 0.30 mm is an editable simulation assumption.
